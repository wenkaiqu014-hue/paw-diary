## 当前交付

健康页保留“档案/待办 → 趋势/足迹 → 完整记录”。同一桌面断点双卡高度稳定，四态切换不移动图表，长列表内部滚动；手机与大字号工具可达。宠物卡内直接切换、添加、原生拖动排序及上移/下移键盘替代；“管理宠物”支持选择与档案编辑箭头，“管理与导出”支持事项选择、编辑/只读完成详情、移入回收站及所选待完成事项ICS。

宠物、健康记录、护理事项可移入回收站和恢复。移入最后宠物后是真空态，添加/恢复入口仍在；恢复宠物不复活此前独立删除的子记录。恢复记录不自动重启因删除而取消的待办，事项删除/恢复不丢完成记录或虚构完成历史。社区帖子仍为不可撤回的本地删除，不被宣称可从健康回收站恢复。

完整规范数据为V3，键`paw-diary:v3:demo`；旧v1/v2原文及既有备份保留，坏源不回填示例。删除标记与宠物排序持久化，批量先验证后一次保存；写失败保留数据、选择和表单，可重试。JSON包含回收站；旧备份复活隐藏资料需显式勾选冲突，父宠物隐藏时不能只恢复子记录。CSV/ICS排除已删除资料与隐藏宠物；新版所有ESM资源按v0.2.0加载以避免旧模块缓存混用。

记录编辑/筛选、护理三态、改期、幂等完成与可选下一次、JSON恢复预览/冲突、CSV/ICS、手机记录卡及原四页本地社区流程均保留。

## 用户体验路线

1. 健康页底部添加宠物，点条目切换；拖动把手或上移/下移排序，刷新确认。
2. 左侧“管理宠物”勾选，右箭头编辑；移入回收站，再从完整记录工具区的回收站恢复。
3. 右侧“管理与导出”勾选待完成事项导出ICS，切状态选择会清空；已完成事项只查看完成事实，不重新完成。
4. 移入一条健康记录、导出完整JSON、恢复旧备份预览，确认不会默认复活已删资料；CSV只导出当前可见筛选结果。
