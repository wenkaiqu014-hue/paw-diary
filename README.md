# 爪爪日记 · 记录每一天的陪伴

**在线体验：[wenkaiqu014-hue.github.io/paw-diary](https://wenkaiqu014-hue.github.io/paw-diary/)**

为养猫狗新手设计的成长手账：记下健康与日常，安排下一次护理，回看毛孩子的成长。也可以浏览公开宠友和社区，在同城找到一起交流、散步的伙伴。

打开网页就能开始，**不用安装，也不用先注册**。健康档案可以保存在当前浏览器；需要私有云同步或社区互动时，再用内测码和邮箱验证码登录。社区和宠友发现使用独立公开资料，登录不会自动上传本地健康档案。

## 可以做什么

**记录与提醒。** 为每只宠物建立档案，记录体重、疫苗、驱虫和生活点滴。已发生的事保存为成长记录，未来安排保存为计划；可明确选择加入健康待办，完成后再记下实际发生的事。支持自定义记录类型、原文件附件、筛选与导出。

**照片与成长回顾。** 设置宠物头像，保存成长照片、重命名并播放幻灯片。选择最近7天、30天或自选日期，查看依据真实记录生成的回顾。分享默认使用简短摘要，进入社区编辑器后还能核对标题、正文、图片、话题和地域，最后确认才公开。

**公开身份与宠友发现。** 从头像菜单进入「个人资料」，设置发帖昵称和公开头像。主动加入发现后，宠友才能浏览你的地域、猫狗类别、交流目的和简介；退出发现会撤下发现卡片，已发表内容继续显示作者昵称和头像。邮箱只在自己的资料页显示。

**真实社区。** 社区与宠友两页都提供「全部／同城」。可按话题、关键词或作者浏览帖子，打开详情评论、点赞；作者可以编辑和删除自己的内容。举报提交后等待维护者处理，也可以只为自己隐藏帖子，在个人资料页的「已隐藏内容」中恢复显示。社区和宠友页面展示真实公开内容。

**便捷启动。** 右上角个人菜单可选择「安装桌面版」，手机显示「添加到主屏幕」。浏览器支持时打开系统安装确认，其他情况提供操作说明。

**自己掌握的资料。** 健康档案、护理事项和个人照片保留在自己的资料空间。跨空间迁移先预览、再确认；完整备份包含媒体与回收站信息。界面支持中英文切换，名字与用户输入保留原文。

**帮助与便捷启动。** 首次确认版本新内容后，六步高亮指引带你认识主要入口，每一步都可以跳过。头像菜单和首页的使用帮助随时可重看，编辑中的输入会保留。帮助内提供Windows、iPhone和Mac安装说明，支持的浏览器可将网站添加到桌面或主屏幕；发现新版时由你选择更新，保存中或有未保存输入时会先保护当前操作。

## 三分钟开始体验

1. [打开爪爪日记](https://wenkaiqu014-hue.github.io/paw-diary/)，先浏览示例，或点击「开始记录我的宠物」建立自己的档案。
2. 点击「记一笔」，手动填写或用一句话整理草稿。逐条核对宠物、用途、日期和记录类型后保存；需要护理提醒时，选择计划并设置日期。
3. 打开「社区」或「附近宠友」，先浏览公开内容。两页均可切换全部／同城；手选城市与行政区，也可点击定位获取建议，再明确确认使用。浏览城市和个人所在地分别选择。
4. 想发帖、评论或加入宠友发现时，用邮箱验证码登录，再在头像菜单设置公开昵称。发帖表单核对内容和公开图片后，点击确认发布。
5. 不想继续看某篇内容时，可以个人隐藏；在「个人资料 → 已隐藏内容」恢复。分享成长回顾时，先检查摘要，再进入社区编辑器确认。

## 使用说明

免登录健康资料只保存在当前浏览器，建议定期导出备份。邮箱登录后的私有健康档案与照片只供本人访问；迁移本地资料需要主动确认。公开帖子仅包含你确认的内容和选中的图片，公开身份与私有宠物档案分别管理。

定位在点击后才请求浏览器权限，用于建议城市和行政区。确认前不会改所选地域；拒绝、失败或额度用完后仍可手选。加入宠友发现需要城市、宠物类别和交流目的，发帖城市可以留空。

AI提供有限额体验，访客无需配置密钥。点击整理、生成或发送后，必要文字与当前宠物记录片段才交给服务端模型；失败或额度用完仍可手动记录。失败尝试也计入AI额度，按北京时间每日重置；回顾与助手展示来源，助手保持只读。护理日期由你设置；日历导出为 ICS 文件，需要自行导入日历客户端。

个人隐藏只影响自己的阅读。恢复隐藏标记不会让已删除或下架的帖子重新公开；举报不会即时自动删除内容，维护者会按队列处理。

## 本地开发

使用 Node 22 和 Python 3：

```sh
npm ci
npm run serve
```

访问 `http://127.0.0.1:4178/`。应用使用原生 HTML / CSS / JavaScript，通过 esbuild 构建；开发服务提供 `dist` 中的网页，修改代码后需重新构建。请通过 HTTP 打开，不直接双击 `index.html`。

运行单元测试：

```sh
npm test
```

浏览器检查使用 Playwright，入口为 `test_app.py`，扩展用例在 `tests/e2e/`。可通过 `PAW_DIARY_TEST_URL` 指定网页。截图与测试资料保存在不提交到 Git 的 `test-results/`。

云端配置见[云配置说明](docs/operations/cloud-setup.md)，部署与回退见[操作说明](docs/operations/deploy-and-rollback.md)。前端只使用公开配置，管理与供应商密钥只在服务端或本机管理环境读取。开发与验收过程记录在 [SESSION_LOG](SESSION_LOG.md) 和 [PENDING](PENDING.md)。
