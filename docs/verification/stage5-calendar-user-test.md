# 阶段5：日历网页版实际导入

用户已确认Google Calendar和Outlook网页版都能登录，不需要下载桌面版。下列操作由用户在独立测试日历中完成，当前尚未实导；不能把ICS格式测试当客户端通过。

准备两份文件：`paw-stage5-original.ics`含2026-10-10与10-12两项全天“纯合成护理事项”；`paw-stage5-rescheduled.ics`保持相同UID，将第一项改到10-11，第二项保持10-12。文件由本产品`src/domain/calendar.js`实际导出函数生成，事件各2个、无VALARM，纯合成、不代表真实护理安排。

Google Calendar：打开电脑网页版设置→导入和导出；先创建／选择“爪爪日记验收-20261008”独立日历，选original文件并导入。确认两个日期、标题和全天属性；再导入同一文件，记录变成几项。再导入rescheduled，记录第一项是否更新、增加重复项或保持旧日期。查看客户端默认通知，不把没有文件内通知当故障。

Outlook网页版：添加日历→从文件上传，选择original及本轮独立测试日历。以相同步骤检查首次、重复、改期结果与通知。实际菜单文字随账号界面核，不在未登录状态声称当前入口已实测。

回复每个平台的“首次日期／数量、重复后的数量、改期后的日期／数量、通知默认、遇到的问题”即可；也可使用Windows包对应calendar-google和calendar-outlook检查项。无需发送邮箱、已有日历内容或实际宠物健康资料。

验收后只清理本轮新建的测试日历，保留原日历。历史旧空Apple Calendar清理未确认，本轮不操作它。

操作来源沿用[日历客户端说明](../operations/calendar-clients.md)中的官方链接，正式实导再记录当次实际菜单／版本。文件导入不自动同步站内后续改期；客户端重复／更新结果以本次观察为准。
