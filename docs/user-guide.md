# 爪爪日记使用指南

体验入口：https://wenkaiqu014-hue.github.io/paw-diary/

本文说明当前业务的使用方法，以及阶段5候选的帮助、指引和安装路径。阶段5能力以正式版本验收为准。界面可切换中英文，用户填写的名字、备注和帖子保留原文。

## 开始使用与空间

先用示例了解界面；准备记录自己的宠物时，切换到本地空间。本地资料属于当前浏览器，不会把示例当成你的真实档案。登录后使用账号的私有云端档案，在其他设备登录同一账号即可访问。迁移本地档案需要预览和亲自确认，切换账号或空间前先保存编辑。

头像菜单和首页的“使用帮助”提供九个主题、重看指引、新内容与安装说明。帮助不需要宠物、登录、网络或AI。正式版本的新内容只在点击“确定”后记住；关闭或Esc可稍后再看。第一次确定后可立即看六步指引，每一步都有“下一步”和“跳过指引”；Esc也能退出，遮罩空白不会推进。正在编辑或保存时，指引会等待你完成操作。

公告和指引偏好只保存在这个浏览器，未登录时示例与本地共用，登录后按身份分别记住。不同设备、独立安装容器或浏览器拒绝存储时，可能再次提示。重看指引不会清空健康资料；有未保存输入时先保存或关闭编辑。

## 宠物与多宠

首页添加宠物，填写名字和类型；生日不确定时可填写估计月龄。点击宠物卡选择当前宠物，录入前核对宠物名。管理页可以编辑、排序和移入回收站。多宠记录筛选支持一个或多个宠物。

## 记录、计划和护理待办

已经发生的事情选“记录”，未来安排选“计划”。先选用途，再核对日期和类型。记录不会因为名字像疫苗或驱虫就自动生成待办。

计划勾选“加入健康待办”才进入护理列表，疫苗与驱虫默认勾选，其他类型按需要选择。未完成计划可在成长足迹和完整列表查看；完成计划才形成已发生记录。

## AI核对与手动路径

“一句话记录”仅提交你主动输入的内容；登录使用资料时按界面说明授权必要片段。AI先生成草稿，逐条检查用途、宠物、类型、日期和护理选择，点击确认才写入。模糊日期需要补填，AI不会替你创建未知类型。

额度耗尽、网络失败或模型不可用时，直接使用手动记录和计划。助手与回顾也不能替代医疗判断；依据兽医给出的安排记录和提醒。

## 成长回顾与分享

首页可选最近7天、30天或自选日期。先看当前宠物实际记录的统计，再生成和核对回顾；没有数据先记一笔，不虚构经历。分享先预览摘要，发布社区前再确认文字。私有健康资料、附件与原始记录不会自动公开。

## 社区、隐私与同城

匿名可以浏览真实公开帖子和宠友资料，发帖、评论和点赞需要登录。在个人资料设置昵称与头像；主动加入宠友发现后，才展示你选择的地域、宠物类型、目的和简介。邮箱与私有健康档案不随公开卡展示。

同城可以手动选择地域，定位只提供建议，拒绝定位仍可手选。遇到不适合的内容可以举报或隐藏。社区没有私信。

## 照片、附件、备份和回收站

照片墙可上传、命名和播放照片；记录附件保留原文件。上传失败先保留输入，检查网络与界面的大小限制。

清除网站数据、换浏览器、迁移设备或卸载前导出完整备份。恢复前看清预览和日期，旧备份不代表最新档案。删除内容进入回收站；恢复子记录前先恢复所属宠物，永久删除时核对对象。

## 日历导入

护理待办导出的ICS文件是当时安排的快照，不是订阅；站内改期不会自动同步。再次导入可能产生重复，结果取决于客户端，先检查日历。文件没有VALARM，是否出现通知由日历客户端设置管理。

验收用独立“爪爪日记验收”日历，核对日期、标题和备注。仅清理本轮确切测试日历，不删除其他安排。Google、Outlook或Apple日历需要在实际客户端亲验；没有账号可标记未验证。

## 安装和安全更新

Windows优先使用Edge菜单安装；浏览器提供真实安装事件时，界面才出现可执行的一键安装。iPhone在Safari中用“分享→添加到主屏幕”，系统提供“作为网页App打开”时按提示设置。Mac Safari只有支持的版本才显示“添加到Dock”。没有安装事件时按菜单说明操作，不承诺首次访问就出现提示。

本地档案属于当前浏览器或独立安装容器，安装不保证迁移。Mac Safari网页App不共享Safari网站数据；安装窗口中档案为空不代表原浏览器档案丢失。要使用同一份资料，可登录云端，或在原浏览器导出备份，再在目标容器预览确认恢复。

安装不等于离线同步或系统通知。本轮不注册缓存worker、不拦截请求。出现新版提示时先保存或关闭编辑，再确认刷新；更新保留当前页面入口。检查失败继续用当前版本，卸载或清除网站数据前先备份。

用户设备的真实安装、定位、读屏、软键盘和日历导入，以三端验收报告记录为准；桌面模拟不替代这些检查。

右上角个人菜单可直接选择“安装桌面版”（手机为“添加到主屏幕”）：浏览器提供安装事件时直接请求原生安装确认，否则显示平台操作说明。
