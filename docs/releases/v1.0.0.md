# 爪爪日记 v1.0.0 · 邀请内测

体验地址：https://wenkaiqu014-hue.github.io/paw-diary/

登录与首次注册需填写邀请者私下提供的内测码及邮箱验证码。合法旧账号保留内测资格；退出后重新登录仍需填码。示例、免登录本地记录、公开社区浏览和原匿名AI体验继续可用。

服务端统一验证账号资格并限制验证码频率，错误内测码不会触发邮件发送。码值仅保存在服务端；本地健康档案不会因登录而自动上传。

保留健康记录与计划、照片与完整备份、AI确认草稿与真实成长回顾、主动公开的宠友资料、社区互动、双语帮助及可安装网页。帮助正文新增键盘可达的阅读区域，选择目录后可进入正文。

日历导出是ICS文件快照，通知由日历客户端管理。Apple Calendar重复导入当前样例保持两条；导入改期文件可能保留已有日期，需要自行编辑或在独立新日历导入。网页没有提供日历订阅同步。

Windows附件为自包含验收包，不含账号、浏览器profile、内测码或健康资料。体验反馈请按设备、站内版本、步骤与脱敏错误记录发送给邀请者。
