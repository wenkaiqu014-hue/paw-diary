## 尚未验证与实际限制

实际手机软键盘、屏幕阅读器及浏览器原生200%缩放未测；短viewport、逐元素字号加倍和CSS zoom=2仅为近似，不能当对应真机结果。Impeccable detector缺解析模块而退化regex，不用其空结果宣称全部界面合规。真实登录、云端/模型、跨账户、多用户社区属于后续阶段。

Calendar AppleScript的open/清理空测试日历返回AppleEvent处理失败；最终以用户实际导入及双方截图确认，不把脚本失败说自动成功。本轮创建的空测试日历“爪爪日记阶段1验收-20261006”清理未确认，不删除或更改其他日程。已导入的测试护理事项由用户确认保留/处理，后续不重复导入。

## 用户体验路线（约三分钟）

1. 打开本地首页，确认顶栏“本地体验”，近期护理在趋势之前；记一笔后刷新仍在。
2. 健康页编辑一条记录；新增护理事项，修改日期，再记录完成并选择安排下一次；只修改本次完成备注，下一次待办仍存在。
3. 导出JSON，再恢复同份文件：先看预览，确认后不增加重复记录；筛选记录导出CSV，勾选pending事项导出日历。
4. 手机宽度查看记录卡、保存/取消和四入口。日历实际导入已由本轮截图核对，不必再次导入验收文件。

用户确认后再决定在原地址发布候选v0.2.0；发布流程和回退见[部署说明](../operations/deploy-and-rollback.md)。完成本地验收不自动开始阶段2或批准收费。
