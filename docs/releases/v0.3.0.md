## 这版带来的变化

不登录也能建立自己的宠物档案，示例与个人资料分开。可以自定义宠物和记录类型，更换头像，为当前宠物保存多张照片，主动播放幻灯片，并切换中英文界面。

用邮箱验证码登录后，可以在另一个浏览器查看自己的私有健康档案。自己的本地资料先预览、再确认迁移，登录不会自动上传；健康资料和照片不向其他账号开放。退出后回到本地个人空间。

记录、护理事项、多宠排序与回收站沿用原有规则。完整备份带照片，恢复先预览并确认，不自动复活已删除资料。保存失败保留草稿、照片和说明供重试；同时修改时先提示冲突。AI、真实社区、微信及手机号登录尚未接入，附近宠友和社区继续明确标识为示例。

## 三分钟体验路线

1. 点击「开始记录我的宠物」，添加宠物、记一笔护理或生活记录，在健康档案查看，再给当前宠物上传照片。
2. 导出完整备份；恢复时查看预览，再决定是否确认。示例与个人资料不会自动互相迁移。
3. 点击「登录与云同步」，通过邮箱验证码登录，预览并迁移自己的本地资料；在另一个浏览器登录同一账号核对档案与照片。
