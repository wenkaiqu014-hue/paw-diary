# 爪爪日记 · 记录每一天的陪伴

**在线体验：[wenkaiqu014-hue.github.io/paw-diary](https://wenkaiqu014-hue.github.io/paw-diary/)**

为养猫狗新手设计的成长手账，把健康记录、护理待办和成长照片放在一起。随手记下今天的小事，安排下一次护理，回看毛孩子的成长。

也可以用一句话整理记录草稿，核对后保存；依据真实记录生成成长回顾，或向只读助手询问网站用法和当前宠物的记录。

打开网页就能体验，**不用安装，也不用先注册**。你可以先浏览示例，或直接建立自己的宠物档案；需要跨浏览器查看资料时，再用邮箱验证码登录。

## 用它记录什么

**健康与日常。** 记录体重、疫苗、驱虫和生活点滴，支持自定义宠物和记录类型。为每只宠物建立独立档案，切换查看，回顾成长足迹。

**接下来的照顾。** 把下一次护理安排成待办，查看近期事项、记录完成情况，也可以导出日历文件。

**一起成长的回顾。** 选择最近7天、30天或自选日期，查看真实统计与成长日记，展开记录依据后私有保存。分享前可编辑预览、复制文字，默认不带健康数值。

**值得留下的照片。** 设置宠物头像，为当前宠物建立照片墙，主动打开幻灯片，随时播放、暂停或退出。

**自己掌握的资料。** 不登录时保存在当前浏览器；登录后使用自己的私有云档案。迁移本地资料前先预览、再确认，不会因为登录就自动上传。支持包含照片的完整备份、健康记录表格导出，以及宠物、记录和护理事项的回收站恢复。

界面支持中英文切换，宠物名字与记录内容保留你输入的原文。

## 三分钟开始记录

1. [打开爪爪日记](https://wenkaiqu014-hue.github.io/paw-diary/)，点击「开始记录我的宠物」，添加一只宠物。
2. 点击「记一笔」，手动填写或用一句话整理草稿；核对宠物、日期和内容后确认保存，再设置提醒。三步引导可以暂停、继续或跳过提醒。
3. 需要云端保存时，点击「登录与云同步」，用邮箱接收验证码。进入云端档案后，选择自己的本地资料，预览并确认迁移。

也可以先逛逛示例，再决定是否开始记录自己的宠物。

## 使用说明

免登录资料只保存在当前浏览器，建议定期导出备份。邮箱登录后，自己的健康档案与照片不会向其他账号公开；本地与云端是不同的资料空间，迁移需要主动确认。

护理日期由你设置；日历导出是 ICS 文件，需要导入日历客户端，不会自动配置系统通知或同步后续修改。

AI提供有限额体验，访客不需要配置密钥。点击整理、生成或发送后，必要文字与当前宠物记录片段会交给硅基流动；失败或额度用完仍可手动记录。失败的模型尝试也计入额度，次数按北京时间每日重置。回顾与助手展示来源，助手不代写档案、不提供医疗建议。

附近宠友与社区目前是明确标识的示例体验，帖子、点赞和评论不会分享给其他访客。真实社区、微信及手机号登录尚未开放。

## 本地开发

使用 Node 22 和 Python 3：

```sh
npm ci
npm run serve
```

访问 `http://127.0.0.1:4178/`。应用使用原生 HTML / CSS / JavaScript，通过 esbuild 构建；开发服务提供 `dist` 中的网页文件，修改代码后需重新构建。请通过 HTTP 打开，不直接双击 `index.html`。

运行单元测试：

```sh
npm test
```

浏览器检查使用 Playwright，入口为 `test_app.py`，扩展用例在 `tests/e2e/`。默认检查本地服务，可通过 `PAW_DIARY_TEST_URL` 指定网页地址。截图与备份保存在不提交到 Git 的 `test-results/`。

云端接入见[云配置说明](docs/operations/cloud-setup.md)，部署与回退见[操作说明](docs/operations/deploy-and-rollback.md)。前端只使用公开配置，管理密钥不能放进网页。GitHub Pages 工作流只发布网页产物，文档修改不会重新部署应用。
