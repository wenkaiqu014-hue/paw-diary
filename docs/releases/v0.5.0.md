# v0.5.0：记录、计划和档案体验

四个健康入口使用统一弹窗，默认类型按入口调整；发生记录和未来计划分别保存，健康待办可勾选。手动与一句话记入并排，切换保留输入及草稿；缺失日期需补填后确认。

建档/编辑提供猫、狗和上传三圆头像；弹窗默认聚焦标题。四个内置类型保留不可删除，最多三个自定义类型，可重复选择书本、爪爪、水滴图标。全站下拉统一，支持键盘和类型管理。

记录/计划支持原图片和PDF，每项最多三个、单文件5MiB，与头像/照片共享50MiB空间限额；私有预览下载、确认删除、失败重试和完整备份。大附件使用短时私有下载，原文件哈希核验通过。

宠物六点拖动整行并支持键盘排序，添加/管理集中右上；全部成长记录可复选宠物，默认当前，表格和CSV显示宠物名。

325单测、实际本地浏览器、可信云目录/计划/文件及5MiB边界通过。原URL新增主线与双模式/语言/布局公开复验通过，构件哈希与本地一致。真实社区、定位和最终真机/读屏验收仍是后续阶段；用户亲验单列。

超过三个或重名的目录合并明确拒绝、原资料不变，先调整目录再试。原v0.1.0至v0.4.0标签保持，固定体验网址不变。
