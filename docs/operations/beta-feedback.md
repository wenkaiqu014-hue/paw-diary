# 内测反馈

首批由邀请者在现有聊天渠道邀请约5–6人，登录与首次注册需用户自行输入私下收到的内测码及邮箱验证码。共用码不作为公开资料，不发到群截图、仓库或问题报告。免登录本地档案和公开社区仍可体验。

遇到问题先记录当时页面与操作，再联系邀请者；不要为了复现清浏览器资料或反复发送邮件。数据保存或私有权限问题优先回报，邀请者据实际情况安排修复或一致回退。站内没有新增反馈后台；是否发送由用户自行决定。

可复制以下模板，截图遮盖邮箱、内测码、验证码、token、真实宠物健康内容、照片个人信息及定位坐标。无需发送账号、邮件正文、备份或完整浏览器profile。

```text
设备/系统版本：
浏览器及版本（网页/独立App）：
站内版本：
页面/路线（例如 #health）：
复现步骤（使用合成内容）：
预期结果：
实际结果与错误文字（脱敏）：
是否每次发生/网络情况：
安全截图（可选，已遮盖个人信息）：
```

Windows集中验收另用v1.0.0包导出JSON/HTML，旧版原始报告不改写。报告只能证明实际执行项目；自动HTTP、桌面模拟和DOM读屏检查不能代替真机、系统App升级或实际朗读结果。
