# 阶段5用户三端验收清单

本清单全部初始not-run，技术验收与用户亲验独立。候选v0.8.0尚未部署时，新版项目记unverified；待原网址正式更新后再执行。结果只填场景、设备/浏览器版本、pass/fail/unverified及原因，不填邮箱、token、坐标或真实健康内容。

原网址：https://wenkaiqu014-hue.github.io/paw-diary/

10分钟快速路径：public-version → notice-confirm/guide-step-1至6/guide-skip → local-save → health-plan → windows-install/windows-launch。完整三端建议30–45分钟，实际耗时按设备与登录情况记录。Windows负责Edge安装/独立启动/卸载与Narrator；iPhone负责真实键盘/GPS/主屏幕安装与VoiceOver；Mac负责Chrome/Safari启动更新与VoiceOver、Apple日历。软键盘/GPS/读屏不能用桌面模拟代勾。

每个ID独立记录：操作 / 预期 / 证据 / 清理。任一失败需原因，没有设备/账号/实际新版记unverified，不选pass。

## 日历与数据边界

Google/Outlook登录条件先核；不代注册、不代勾。日历三种客户端各有独立first/repeat/reschedule ID，汇总calendar-*项目仅记录跨客户端归纳，不能覆盖单客户端失败。两个测试计划是不同日期全天事件；导入先核日期/标题/备注，重复导入记录数量变化，改期再导入记录实际新旧事件。ICS不含VALARM，站内改期不自动同步；另核客户端通知默认设置。只清本次“爪爪日记验收”日历，旧空Calendar清理未确认不处理。

本地档案属于当前浏览器/存储容器，安装不保证迁移或同步；Mac Safari网页App与Safari网站数据独立。需要同一份资料时登录同账号，或从原浏览器导出备份，在目标窗口预览确认恢复。只卸载新建测试App，不清全部浏览器资料。

Windows验收包双击START-HERE.html，不要求Node/Python/管理员；RUN-CHECK可选，不改执行策略。公共资源自动成功仅是HTTP证据，人工安装/定位/读屏/账号边界保持单独状态。导出JSON恢复进度，导出HTML便于阅读；报告不自动上传。
