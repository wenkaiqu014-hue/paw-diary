# 爪爪日记：两到三分钟体验路线

打开 https://wenkaiqu014-hue.github.io/paw-diary/ 。首次确认新内容后会进入六步指引，每一步都可以下一步或跳过；头像菜单“使用帮助”可重新打开。

第一分钟先看示例档案的成长记录与护理待办，再选择“开始记录我的宠物”。填写名字、猫狗类型和生日或估计年龄；自己的本地档案与示例分开。记一笔已经发生的日常或体重，保存并刷新，确认刚才的内容仍在。

第二分钟安排一项未来护理：用途选择计划，按需加入健康待办。完成事项时再记录实际发生的事；日历导出是文件快照，需要自行导入客户端和设置通知。成长回顾依据当前宠物已有记录；AI不可用时继续手动记录。

有余力时打开社区或附近宠友，查看真实公开列表与全部／同城筛选。发布和互动需要邮箱登录及公开昵称，回顾摘要须最后确认才公开；健康与照片不会自动公开。公开列表为空时就展示空状态，不补假用户或帖子。

想便捷启动，在帮助中查看添加到设备的步骤。安装窗口可能有独立存储，需要同一份档案时登录云端或先导出备份；网站更新由本人点击，有未保存内容时先回原编辑。

这条路线不代表用户已完成真机、系统安装、读屏或三个日历客户端验收。具体检查用stage5-user-checklist与Windows ZIP，未执行项保留未验证。
